# 纸上陕北

中国陕北传统文化纸艺互动H5。在线体验：https://eclipsezzx.github.io/yulin/?v=20261017-web1

当前版本20261017-web1，基于20261017-flow1完整流程做图片与首屏加载优化：序章折剪/自由窗花；第一章山河遗迹；第二章四道美食裁剪、盛盘与知识热点；第三章15秒安塞腰鼓随乐互动；第四章绥米唢呐《大摆队》；终章从空底景开始自由拼贴陕北，可双指或滚轮缩放，保存2400×1600PNG。

直接部署仓库根目录到GitHub Pages即可。js/包含全部可编辑源码，入口index.html使用game.bundle.js；修改独立JS后运行python build.py重建。图片使用WebP、透明通道保留；封面字体使用本地小字集，后续正文所需字形再按需加载。新版本保留既有本机进度与剪口。

docs/固定美术规范.md为美术要求；docs/图片优化报告.json为压缩明细。仅发布网页所需素材，不包括生成PNG原图、研究视频、旧的长音频及本机草稿。图片原图保留在本机项目资料目录。

# 一纸陕北：序章至第一章新版

本次实现：新版首页、序章《一张纸的来处》、第一章《山河与边塞》。从剪去与留下进入山河，再认识榆林红山上的镇北台与互市遗存。第二章及以后保留此前实现，目录明确标注“此前版本”。

## 互动和动画

展开纸卷；真实触屏剪外轮廓与内部孔洞；保留玩家剪口；剪开连接处、撤回并提起；分层山景视差；窗口与高台入场；两件纸片自由摆放；纸页转场和按钮反馈。无需播放预渲染视频。旁白为页面文字，没有虚构讲述者、采访或录音，没有收件人或带走地名步骤。

前两章十一处互动／叙事节点，加首页开场。原剪纸外轮廓机制保留明显剪偏重试、松手续剪和辅助完成。内部镂空引导回到剪口继续。连接教学限定于本次单张纸作品，不代表所有剪纸都不能分片。

沿用 yizhi-yulin-v1 本机存档。既有章节进度保留；序章／第一章现在采用新版流程。新版叶形与山梁保存在 handCuts 中；后续旧版终章尚未将这两项加入素材库。

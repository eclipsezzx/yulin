## 已完成

序章：开场说明 → 三次对角折叠 → 锯齿纹、小花叶、月牙纹、中心花蕊、花瓣轮廓五段剪刻 → 按折叠顺序三次展开 → 观察自己的团花 → 安塞年节窗花 → 序章结束。去掉“单张纸连接处”独立教学，没有采访、录音、收件人或带走地名流程。

## 教程与核查

- 桐庐博物馆发布、杭州网承载的《在线学剪纸·第五课·团花的剪纸技法》：https://z.hangzhou.com.cn/2020/rwwhql/content/content_7748776.htm 。四折花部分明确列出三次对角折叠、描样和剪制步骤。
- 烟台市政府网站公布的莱阳市榆科顶初级中学劳动教育报告“学剪团花”教学设计：https://www.yantai.gov.cn/art/2024/9/18/art_110920_3214486.html 。用折、画、剪介绍团花，三次对折以中心点定位，装饰纹样由小到大及外缘。
- 中国非遗网《安塞剪纸》：https://www.ihchina.cn/project_details/13934.html 。支持喜庆日子、年节剪纸与贴窗花的生活说明。

采用教程的折剪原理，花样为原创的适中难度数字教学设计；不复制页面作品，不声称是安塞某位艺人的传统作品或安塞独有折法。三次折叠形成八层，对称的八个半扇区组成四折团花；不把八层等同于八瓣花。

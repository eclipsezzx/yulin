# 最新序章流程与旁白

开场：窗上的一朵花，往往从几道折痕开始。把红纸叠好，再让剪刀沿着花样走。

三次对角折叠；依次剪锯齿、小花叶、月牙、中心花蕊、外缘；逐层展开；最后进入安塞年节窗花场景。

沿折边剪一列小锯齿。展开后，两侧的剪口会相向合拢，成为细密的花纹。

靠近花心，再剪一个小花叶。内圈的细纹和外圈的月牙相隔，花样才有疏密。

再剪一道弯弯的月牙。弧线落在折边上，展开时便合成一片舒展的花叶。

在中心尖角剪一个小弧口。纸一层层打开，这一道弧会围成花蕊。

最后剪外缘。让曲线时收时放，纸上的花瓣就有了起伏。

把两只对角合在一起。第一道折痕，先把方纸分成两半。

沿三角形的中线再折一次。边角对齐，叠在一起的纸才会留下相同的花样。

再合拢一次。三道折痕，把纸叠成八层；一段剪口，会在展开时绕着中心重复。

第一章继续使用此前版本，本次不改章节内容。

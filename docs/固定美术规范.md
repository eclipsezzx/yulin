# 一纸陕北：固定美术规范

用户于2026-10-15明确指定。此规范用于本项目后续所有新美术和界面；以用户后续明确修改为准。参考只约束美术语言，不直接复制构图。

## 整体风格

中国陕北民俗文化主题的当代纸艺拼贴插画，融合传统剪纸、套色版画、复古文旅海报与现代艺术画册排版。具有鲜明的手工印刷质感与精致的编辑设计感。严格参考附图的美术风格，不直接复制其构图。

## 固定配色

以温暖米白纸色为底，朱红、青蓝、赭黄、墨黑为核心色：米白 #F4EBDD；朱红 #D83A25；青蓝 #218A98；赭黄 #BC8D4D；墨黑 #24221E。朱红用于人物服饰、剪纸和视觉焦点；青蓝用于河流、山体与局部衬色；赭黄用于黄土、建筑与石材；墨黑用于文字、轮廓和暗部。允许少量暗绿表现植被，不引入其他鲜艳主色。同系列保持一致的色温与饱和度。

## 材质与表现

使用真实感细腻的米白纸纹、自然不规则的撕纸边缘、纸片叠压、局部折痕、轻微印刷磨损和套色偏移。画面由大小不同的纸片拼合，保留清晰的色块边界、纤维感和少量露出的米白纸缝。阴影轻薄克制，表现纸张层次，不做厚重立体效果。正文区域纹理较轻，插画区域材质更丰富，避免满屏脏污和噪点。

## 插画语言

采用精细的平面版画式插画，以概括的大色块建立构图，以细致的刻线、镂空与印刷纹理丰富局部。山川、河流、城墙、窑洞、古建筑与传统文化元素自然融合，形成完整画面，不堆砌独立图标。景物具备清楚的远、中、近层次，画面细节丰富，但视觉主次明确。如出现人物，使用与环境统一的民俗版画人物：比例自然、动作舒展、五官简练、服饰纹样精致，避免写实摄影与幼态卡通。

## 构图与排版

采用纵向画册式构图，突出一个明确的视觉中心。运用不对称布局、斜向纸片、曲线引导和局部出画，形成流动感。大面积插画与米白留白交替，避免所有区域同样拥挤。标题、正文、插画和交互区域保持清晰秩序。同系列保持一致的页边距、标题尺度、文字层级与按钮样式，但各页面可以采用不同构图。

## 字体与界面

主标题使用有力量、清晰易读的黑色毛笔书法字；小标题与说明使用精致中文宋体。只呈现指定文案，不添加无意义文字、英文装饰或乱码。按钮统一为墨黑色胶囊形、米白文字；次级按钮使用米白底、细黑描边。图标使用简洁的黑色线条，避免彩色应用图标。界面与纸艺画面自然融合，不使用成组圆角卡片。

2026-10-15补充：文本不要跟背景融合；旁白放在独立、不透明米白纸面中，配细墨黑边框，黑字清晰，避免插画纹理透过正文。以新增旁白效果图为依据。

## 输出规格

单张独立画面，9:16竖屏，高清细节。直接呈现平面的完整页面，不加手机外壳、透视角度、展示台、外部背景或设计说明。严格沿用参考图的色彩、纸张材质、插画笔触与字体气质。生成网页背景时不烘焙正文和按钮，实际界面由HTML排版。

## 避免

摄影写实、写实人物、日系动漫、Q版人物、表情符号、通用矢量素材、简单几何占位图、油画、水彩晕染、光滑3D、塑料质感、霓虹、玻璃拟态、大面积渐变、强烈光效、厚重投影、过度做旧、杂乱拼贴、模板化旅游网页、额外水印。
